# Test - Pagina Web

Una pagina web moderna e responsiva creata con HTML e CSS puro.

## Come visualizzare la pagina

Ci sono diversi modi per visualizzare la pagina web:

### Metodo 1: Aprire direttamente il file
Semplicemente fai doppio click sul file `index.html` per aprirlo nel tuo browser predefinito.

### Metodo 2: Utilizzare un server locale
```bash
# Con Python 3
python3 -m http.server 8000

# Con Python 2
python -m SimpleHTTPServer 8000
```
Poi apri il browser e vai su `http://localhost:8000`

### Metodo 3: Utilizzare Live Server (VS Code)
Se usi Visual Studio Code, installa l'estensione "Live Server" e clicca con il tasto destro su `index.html` → "Open with Live Server"
